# Sovereign Intelligence API (llm.txt)
> Self-sustaining compute for AI agents. Pure x402 Guest Mode.

## Technical Details
- Base URL: https://api.sovereign-api.com
- Protocol: x402 (Coinbase CDP standard)
- Network: Base (eip155:8453)
- Currency: USDC
- Auth: Stateless Wallet Signature / Micropayment
- Streaming: OpenAI-compatible SSE with built-in normalizer

## API Endpoints
- OpenAI Compatible: https://api.sovereign-api.com/v1/chat/completions
- Model List: https://api.sovereign-api.com/v1/models
- Identity/Wallet Info: https://api.sovereign-api.com/v1/x402/info
- Macaroon Revocation: https://api.sovereign-api.com/v1/macaroon/revoke

## Tools Marketplace (14 Endpoints)
All at /v1/tools/{tool-name}. Auth: Bearer sk-sov-... or x402.
- GET /v1/tools/crypto-price, market-data, ens-resolve, web-scrape, web-screenshot, flight-search, hotel-search
- POST /v1/tools/wallet-balance, web-search, image-gen, tts, transcription, code-exec, embeddings


## Operational Modes
1. Pure Mode (Stateless): Pay exact amount per request. No API keys.
2. Burst Session Mode: Pre-pay with X-Sovereign-Session-Deposit to get high-concurrency Macaroon token.
3. Prepaid Key Mode: Register API key, top up with USDC, use as Bearer token.

## OpenClaw Integration
Sovereign API is compatible with OpenClaw (openclawlab.com).
- Provider type: openai-completions
- Base URL for OpenClaw config: https://api.sovereign-api.com/v1 (must include /v1)
- SSE streams are normalized to strict OpenAI spec (non-standard fields stripped)
- Works with OpenClaw TUI, Web UI, and Telegram channels

## SSE Normalization
All streaming responses are normalized to strict OpenAI Chat Completions spec.
Non-standard upstream fields (provider, native_finish_reason, cost) are automatically stripped.
Compatible with: OpenClaw, Cursor, Continue, custom OpenAI SDK clients.
